# python-control-flow-and-functions
Core Python fundamentals covering control flow, loops, and functions.

A beginner-friendly collection of Python scripts built in a Jupyter Notebook, covering control flow, loops, and functions.

## What's Included

1. **Number Guessing Game**
   - Uses a `while` loop, input validation, and control statements (`break`, `continue`, `else`).
   - Gives the user 3 attempts to guess a random number between 1 and 10.

2. **Multiplication Table Generator**
   - Uses a `for` loop and the `range()` function to generate a table from 1 to 10 for any given number.

3. **BMI Calculator**
   - Defines a custom Python function (`calculate_bmi`) to compute Body Mass Index based on user weight and height.

## Requirements
- Python 3.x
- Jupyter Notebook
